# Gemini 3.1 Pro — Product Launch Film

A high-performance, frame-driven product launch film built entirely with a pure HTML5 Canvas and JavaScript animation architecture. Designed specifically for the Gemini 3.1 Pro brand identity, this piece executes precise cinematic pacing, fluid UI transitions, and custom visual effects without reliance on heavy external video editing suites.

The prompt is taken from [Prompt Motion](https://prompt-motion.com/).

---

## Key Architectural & Visual Features

- **Pure Function Frame Engine (`seek(t)`):** Every frame is deterministically calculated as a pure function of time, ensuring flawless playback consistency, scrubbability, and multi-subframe motion blur support.
- **Liquid Glass Aesthetic:** Implements multi-pass canvas rendering techniques to simulate physical glass—featuring frosted backdrop blurring, edge refraction bending, specular top sheens, rim lighting, and soft pastel auras driven by custom brand colors.
- **Precision Typography & Timing:** Features dynamic word-by-word text activation paired with eased cinematic transitions and gradient highlighting for key value propositions.
- **Rhythmic Asset Synchronization:** Synchronizes image switching on exact 16th-note intervals, aligning high-frequency product screen transitions seamlessly with voiceover phrasing.
- **Custom Brand Integration:** Styled strictly around official Gemini branding parameters, incorporating Google Sans typography, brand-specific color palettes (`#2B3A67`, `#FDE74C`, `#FC7753`), official product screenshots, and the vector logo lockup.

---

## Technical Specifications

- **Aspect Ratio:** 1:1 Square (Optimized for modern social and web display platforms)
- **Resolution:** 1440 x 1440 px
- **Framerate:** 60 FPS
- **Duration:** ~27 seconds (including an expanded end card hold for enhanced readability)
- **Dependencies:** Zero external rendering libraries; pure vanilla HTML5/JavaScript execution environment.
